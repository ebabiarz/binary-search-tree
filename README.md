For this project, I created a Binary Search Tree, using what I learned about recursion and algorithms to do so.

Recursion was used in nearly all of the methods. The #tree_from_sorted_array method used recursion to add pointers to the correct nodes. Several other methods, like #insert, #delete, and #level_order among others, used recursion to traverse the binary tree, arriving at the specified node within it.

Methods like #level_order also utilized queueing to properly traverse the tree and return the sorted nodes. This method, as well as the other ordering methods, also required knowledge from previous lessons to accept blocks.

This project showcases what I've learned up to this point on data structures and algorithms.
